欢迎来到我的 **Hugo** 博客！

## 为什么选 Hugo

- **极速**：几千页也能在毫秒级渲染完成
- **简单**：纯 Markdown 写作，专注内容
- **灵活**：社区有数百款主题，一键切换

## 一个代码例子

```python
def greet(name: str) -> str:
    return f"你好，{name}！"

print(greet("Hugo"))
```
